# Honda 部品モックデータ（Excel 統合ツール用）

部品ID + 部品名 をキーに結合する 16 ファイル。部品名は実在の「○○ASSY」名称、部品ID・金額・在庫・URL・サプライヤー名はすべて架空。

- 基準: `01_部品マスタ.xlsx`（44 部品。2 シート: 部品マスタ / 設定）。02〜16 を結合する。
- 2 シートのファイル: 01, 02, 03, 09, 14（結合時に「他のファイルのシートも含める」を入れるとすべて出力に入る = 計 21 シート）
- 各ファイルに「ID または部品名が一致しない行」が 3〜4 行ある（ID が 1 桁違う / ID は同じで部品名が別物 / マスタに無い部品）。結合キーに ID＋部品名の組み合わせを使うと、これらは取り込まれない。
- `truth.json`: 期待値（検証用）。`merged/`: ツールのエンジンで結合した出力例。`generator/`: 生成・検証スクリプト。
