# サンプルファイル（体験用・テスト用）

「Excel 統合ツール」を試すためのサンプルです。架空の「2027年卒 夏季インターン」の応募者データで、
実際の業務ファイルによくある“ずれ”や“クセ”をわざと入れてあります。内容はすべて架空の人物です。

**試し方**: 5つのファイルをまとめてツールにドラッグ＆ドロップ → 基準ファイルが「01_学生名簿」になっていることを確認 →
「結合する」 → 列を並べ替え → 「Excel出力」。

| ファイル | 形式 | 何を試せるか |
|---|---|---|
| `01_学生名簿.xlsx` | Excel（基準） | 名簿 60 名。数式・書式・グラフ・ピボットを含む「壊してはいけない」ファイル |
| `02_面接評価.xlsx` | Excel | 受験番号（＝学生ID）で結合。ID の書き方がバラバラ、重複・未登録あり |
| `03_連絡先.csv` | CSV（Shift_JIS） | ID がなく「氏名」で結合。同姓同名はメールで見分ける |
| `04_適性検査.xls` | 旧形式 Excel 97-2003 | 「フリガナ」で結合。学籍番号は学生IDと無関係（キーに使えない） |
| `05_研修出欠.xlsx` | Excel | 「氏名＋大学」の組み合わせで結合（同姓同名がいるため） |

## デモの手順

「ファイルを投げる → 結合 → 列を並べる → 出力」の 4 ステップを、サンプルで通しで試す手順です（所要 5 分ほど）。

1. **ファイルを投げる**
   - `samples` フォルダの 5 ファイルを全部選んで、ツールの画面にドラッグ＆ドロップします（1 つずつ足してもかまいません）。
   - 最初に入れた `01_学生名簿.xlsx` が **★基準** になります。各ファイルのカードに行数（名簿 60 / 面接評価 63 / 連絡先 47 / 適性検査 42 / 研修出欠 32）と、
     自動で見つけた結合キー（01・02 は ID、03・05 は氏名、04 は氏名カナ）が出ます。名簿の見出し行は 3 行目、研修出欠は 2 行目と自動で判断されます。
   - 上の「結合キー」欄に `✓ ID` `✓ 氏名` のチップと「基準 60 名 / …」の見込みが出ます。**詳細設定…** を開くと、`02` は「受験番号 ⟷ 学生ID」が「良好」、
     `05` は同姓同名がいるので「氏名＋大学」の組み合わせが提案されているのを確認できます。
2. **結合**
   - 「**結合する**」を押すと、基準（名簿）の表の右に他ファイルの列が追加されます。学生ID の先頭ゼロ（`000100`）はそのままです。
     結合のキーに使った列は取り込まれません（`03_連絡先` の 氏名・メール・電話 は、名簿に同じ列があり、氏名＋電話番号・メール・電話のどれもキーになるため、
     既定では 1 列も追加されません）。結合前の「追加される列」で列名（例: メール）をクリックすると取り込め、同じ見出しは「メール（03_連絡先）」のように
     ファイル名付きで区別されます。元のファイルは変更されません。
   - 右のパネルの「チェック結果」で、未一致・重複・要確認の行を確認できます（行をクリックするとその行へ移動）。
3. **列を並べる**
   - 列の見出しをクリック → **Ctrl を押しながら**離れた列もクリック（例: 学年・年齢・判定）→ そのまま **ドラッグ**して好きな位置へ落とします。選んだ列がまとめて動きます。
   - タイトル行（A1:K1 の結合）にかかる移動では確認が出るので「**結合を解除して移動**」を選びます（見た目はそのまま、**元に戻す**で結合も戻ります）。
   - 列を右クリック →「右に列を挿入」、セルをダブルクリックして入力（日付・%・`=UNIQUE(...)` も Excel と同じに扱われます）。
   - 「平均」のように数式から参照されている列を Delete で消すと確認が出ます。「**参照している数式を値に変換して削除**」で #REF! を出さずに消せます。
   - **元に戻す / やり直す**（Ctrl+Z / Ctrl+Y）は何回でも使えます。
4. **出力**
   - 「**Excel出力**」→ ファイル名（既定は `01_学生名簿_統合_日付.xlsx`）と出力エンジン（「Excel本体で出力（推奨）」または「内蔵エンジン」）を選んで出力します。
   - 出力したファイルを Excel で開くと、「集計」の数式・グラフ、「ピボット」、条件付き書式、入力規則が **並べ替えた後も同じ見出しの列** を指しています。
     確認用のコマンド: `node tools/check-output.mjs <出力したファイル> --base samples\01_学生名簿.xlsx`（`合格 (PASS)` になります）。

**もう 1 つのデモ（基準ファイルを変える／結合キーを自分で選ぶ）**

1. ファイルを `05 → 04 → 03 → 02 → 01` の逆順で入れ、`02_面接評価` の「**☆ 基準にする**」を押します。
   見込みが「基準 63 名 / 未一致 3」（どのファイルにもいない 11・30・49 行目）に変わります。
2. `04_適性検査` は 02 に氏名カナ／フリガナの列がなく、結合キーが見つかりません。結合は止まらず、`04` のカードに
   「**結合対象外（結合キーが見つかりません）**」と **キーを選ぶ…** ボタンが出ます（見込みの行・「結合プレビュー」・警告にも同じ注意が出ます）。
   このまま「結合する」を押すと、`04` を除いた 4 ファイルが結合され（`02` の 9 列に、取り込んだ 18 列）、警告に「列は取り込んでいません」と残ります。
3. `04` を使いたいときは「**キーを選ぶ…**」を押します。詳細設定が `04` のタブで開くので、「**列を選んで結合キーに追加**」で基準ファイルの列と `04` の列を
   1 つずつ（氏名＋大学のように最大 3 列ずつ）選んで「追加」します（手動で足したキーには「手動」の印と × が付きます）。
   キーが選ばれたファイルは結合に戻り、キーの表の下に「このキーで N / 42 行が一致します」と出ます。
   ※ このサンプルには 02 と `04` を結びつける列がありません（`04` の「学籍番号」は大学の番号で、`02` の「受験番号」とは無関係）。試しに
   「受験番号 ⟷ 学籍番号」を選ぶと一致は 0 件で、`04` の列は結合されても空のままです。`01_学生名簿` を基準にして、自動のキーを外してから
   「フリガナ ⟷ 氏名カナ」を自分で選び直すと、一致する行に `04` の値が入ります。
4. どのファイルにもキーがないとき（例: `02` と `04` だけ）は「結合する」が押せなくなり、理由が表示されます。上の手順でキーを足すと押せるようになります。

出力の確認は `--base samples\02_面接評価.xlsx --sheet 面接評価 --header-row 1` です。

**入れてはいけないファイル**（アプリが壊れず、カードにわけを出すかを確かめる）: 途中で切れた・壊れた `.xlsx`、パスワード付きの Excel、0 バイトのファイルは、
そのファイルのカードに赤字で「読み込めません」の理由が出るだけで、ほかのファイルの結合は続けられます（「クリア」で外せます）。`.txt` や画像は受け付けず、
同じファイルを 2 回入れると「すでに読み込まれています」と出ます。

## 01_学生名簿.xlsx（基準ファイル）

- シート「名簿」: 1 行目にタイトル（A1:K1 を結合、太字 14pt、テーマ色の塗りつぶし）、3 行目が見出し、4〜63 行目に 60 名。
  - 見出し: 学生ID / 氏名 / フリガナ / 大学 / 学部 / 学年 / メール / 電話 / 生年月日 / 年齢 / 志望度 / 重複チェック
  - 学生ID は **文字列の 6 桁**（`000100` のように先頭ゼロあり）。生年月日は `yyyy/m/d`、年齢は `=DATEDIF(生年月日,基準日,"Y")`。
  - 「重複チェック」（L 列）は **非表示の補助列**（`=COUNTIF($B$4:$B$63,B4)`）。
  - **ウィンドウ枠の固定**（C4）、**オートフィルター**（A3:L63）、列幅はバラバラ。
  - **条件付き書式**: 志望度 4 以上を強調／氏名が重複している行を赤字（補助列 L を参照する数式ルール）。
  - **入力規則**: 志望度は 1〜5 のリスト、大学は「マスタ」シートの一覧（別シート参照のリスト）。
  - 表の下（1 行あけて 65〜66 行目）に **人数・平均の集計行**（`=COUNTA(B4:B63)` など）。
  - 同姓同名「佐藤 翔太」が 2 人（慶應義塾大学／早稲田大学）。異体字の「髙橋」「齋藤」「渡邉」「山﨑」も含みます。
- シート「集計」: 名簿を参照する数式（`COUNTIF(名簿!$D:$D,…)` のような列全体参照、`名簿!$D$4:$D$63` のような範囲参照、
  `AVERAGEIF` / `COUNTIFS` / `SUMPRODUCT` / `VLOOKUP` / `INDEX+MATCH`、名前 `志望度列`）と **グラフ**（大学別の人数）。
- シート「ピボット」: 名簿（A3:L63）を元データにした **ピボットテーブル**（大学×学年の人数）。
- シート「マスタ」: 大学・学部・学年・志望度の一覧と基準日（2026/4/1）。
- **名前の定義**: `大学一覧`（マスタ!$A$2:$A$20）、`志望度列`（名簿!$K:$K）、`基準日`（マスタ!$H$2）。

→ 列を並べ替えても「集計」の数式・グラフ・ピボット・条件付き書式・入力規則が **同じ見出しの列** を指し続けるか、
  出力ファイルが Excel で **修復なしに** 開けるかを確認できます。

> タイトルが A1:K1 で結合されているため、A〜K 列の一部だけを移動しようとすると、Excel と同じくそのままでは移動できません
> （Excel では「この操作は結合したセルには行えません」）。ツールは確認ダイアログを出し、「結合を解除して移動」を選ぶと
> タイトルの結合を解除して「選択範囲内で中央」にしてから移動します（1 回の「元に戻す」で元どおり）。
> タイトルの塗りつぶしは A1 だけに付いています（B1〜K1 は塗りなし・文字は白）— 結合を解除したときに見た目が保たれるかを確かめる例です。
> 結合された列の外（結合後に追加された列など）は確認なしで自由に移動できます。

## 02_面接評価.xlsx

- 見出しは 1 行目。受験番号 / 氏名 / 面接官 / 評価1〜3 / 平均（`=AVERAGE(D2:F2)`）/ 判定（`=IF(G2>=3.5,"合格","保留")`）/ コメント。
- 受験番号は名簿の学生IDと同じ番号ですが、**書き方がバラバラ**: `000100`（文字列）、`142`（数値でゼロが消えている）、`０００２４２`（全角の文字列）。
- 氏名は **スペースなし／半角スペース／全角スペース** が混在し、**異体字**（名簿の「髙橋」が「高橋」、「齋藤」が「斎藤」など）も。
- **再提出で同じ人が 2 行**（2 名）、**名簿にいない受験番号**（3 名）、**名簿にいるのに面接記録がない**学生（2 名）。
- 平均には **カラースケール** の条件付き書式。2 枚目のシート「評価テーブル」は同じデータを **Excel のテーブル**（`面接評価表`）にしたもの。

## 03_連絡先.csv

- **Shift_JIS** の CSV（Excel で保存した CSV と同じ形式）。列は 氏名 / メール / 電話 だけで **ID がありません**。
- 氏名の表記ゆれ（スペースあり・なし、「様」付き）、電話番号の書式ゆれ（ハイフンなし・かっこ付き）、メールの大文字小文字。
- 同姓同名の 2 人はどちらも載っており、**メールアドレス** で区別できます。名簿にいない人が 2 名。

## 04_適性検査.xls

- **Excel 97-2003 形式（.xls）**。見出し: 学籍番号 / 氏名カナ / 受検日 / 言語 / 非言語 / 合計（数式）/ 性格タイプ / 総合判定（数式）。
- 「学籍番号」は大学の学籍番号で、**名簿の学生IDとは無関係**（見出しは ID っぽいがキーには使えない例）。
- 漢字の氏名がなく **カナだけ**。全角カナ／**半角カナ**（`ｻﾄｳ ｼｮｳﾀ`）／スペースなし が混在。名簿のフリガナと照合します。

## 05_研修出欠.xlsx

- 1 行目がタイトル（結合）、**見出しは 2 行目**。氏名 / 大学 / 第1回〜第3回（○・×・遅刻）/ 出席回数（数式）/ 備考。
- 識別に使える列は **氏名と大学だけ**。同姓同名の「佐藤 翔太」が 2 人いるので、**氏名＋大学** の組み合わせが必要です。
- 大学名の **表記ゆれ**（「慶應大学」「早大」「東大」など）あり。

## truth.json（開発用）

各ファイルのどの行が名簿のどの行に対応するか（正解）を記録したファイルです。自動テストで使います。

## 作り直すには（開発者向け）

```
npm run samples             # Excel が必要（自分専用の非表示 Excel で作成し、終わったら閉じます）
node tools/make-samples.mjs --no-excel   # CSV と truth.json だけ
```

データは `tools/lib/sample-data.mjs`（乱数の種を固定しているので毎回同じ内容）、Excel での作成は `tools/make-samples.ps1`。
ファイルを Excel で開いたままだと上書きできないので、閉じてから実行してください。
